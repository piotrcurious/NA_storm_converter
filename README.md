# NA_storm_converter
Generated by Claude. North Atlantic storm names transcoder.

This system converts classical North Atlantic storm names to corresponding high CO2-emitting corporation names, including their annual emissions data.

## Features
- **Future Proofed:** Contains the rotating lists for the 2024–2029 seasons, including recently retired name replacements (Dexter, Leah, Imani, Farrah, Idris).
- **Comprehensive Data:** Maps storms to major corporate emitters with CO2 emissions data.
- **Dual Search:** Search by storm name or by year and storm number.
- **Supplemental List:** Handles seasons with more than 21 storms using the WMO supplemental list.

## Usage
The primary system is now Python-based for better data management and future-proofing.

### Requirements
- Python 3.6+

### Running the Transcoder
```bash
python3 storm_transcoder.py
```

### Example
1. Select Option 2 (Search by Year and Storm Number).
2. Enter year: `2026`.
3. Enter storm number: `12`.
4. Result: `Storm #12 in 2026 is Leah. Converted to: LADWP (12 million metric tons)`.
